AI 助手配置说明

  1. 本地规则：不用填任何配置，不联网，可以直接管理待办和番茄钟。
  2. API 模型：选择「API 模型」，点下方常用服务自动填充，或手动填写接口地址（通常以 /v1 结尾）、模型名和 API Key。
  3. 点「测试连接」确认能通，再点「保存配置」；之后打开 AI 助手即可对话。
  4. 直接双击页面时可能遇到服务端 CORS 限制，推荐用扩展模式；Key 只保存在本机，导出备份不会包含。

AI 模式

默认使用本地规则引擎，不联网。切换到 API 模式后，对话与本机待办摘要会发送到你填写的服务。

接口配置

助手设定 可选

仅 API 模式生效，会追加到系统提示词。可写角色、语气、回答格式或限制；留空使用默认助手设定。

兼容 OpenAI Chat Completions 接口。地址一般以 /v1 结尾；本地 Ollama 可用 http://localhost:11434/v1。

API Key 只保存在本机 localStorage，导出备份时不会写入；请勿在公共电脑上保存私人 Key。

备份与恢复

导出为 JSON 文件，换设备时再导入；分类、网站、组件与设置都会带上，API Key 除外。也支持直接导入 WeTab 导出的 .data 备份。

存储

数据保存在本机 localStorage（lumenTab.v1），不会上传服务器。

Lumen Tab v1.5.0

一个离线可用的新标签页：分类侧栏、网站与文件夹、小组件、搜索和 AI 助手。可导入 WeTab 备份；默认本地规则，联网入口只有实时天气（Open-Meteo，可切演示）与主动开启的 AI API 模式。

快捷键

  • /聚焦搜索框

  • ?打开快捷键说明

安装为浏览器新标签页

  1. 打开 edge://extensions 或 chrome://extensions
  2. 开启「开发者模式」
  3. 选择「加载解压缩的扩展」，指向本目录 product/
  4. 新开标签页即生效

天气默认实时（Open-Meteo），可在设置 → 外观切到演示；热榜、名句为内置演示数据。
